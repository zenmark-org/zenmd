## Added

- The built-in plugins (code colours, diagrams, checklists, quizzes, runnable code, ratings) and layouts (docs, post, landing, wide, handout, slides, course, glossary, release, troubleshooting).
- Find in page, the editor, and printing.
- MyST, beside CommonMark and GFM: Settings › Reader, or `markdown.dialects` in `.zenmd.yml`.
- Export to a website and to a PDF: `zenmd export site` and `zenmd export pdf`, File › Export, and Settings › Export, with the same options everywhere.
- Blueprints and page templates: File › New from Blueprint…, `zenmd init --blueprint`, New Page from the folder's page template, and Settings › Templates.
- Glossaries, with one file per term and an A–Z index built from them.
- A Reload button in the sidebar header, and ⌘R.

## Changed

- Export settings are under `export:` in `.zenmd.yml`.
- Settings › Markdown is now Settings › Reader.

## Fixed

- An export notes a user-scoped plugin option of the global config once, not on every page.
- `zenmd` path errors name the full path, and a usage error prints one hint instead of the whole help.

The full list is in the repository's CHANGELOG.md.
