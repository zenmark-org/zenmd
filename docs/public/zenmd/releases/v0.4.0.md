## Changed

- The app is now Zenmark, built on the zenmd engine.
- The command is `zenmd`; the engine's Go packages are public under `engine/`.
- The browser runtime is shared by the app and exported sites, so both look the same.

## Fixed

- Diagrams render again.
- Reload keeps the page you were reading.
- Plugins can no longer hang zen, run code that wasn't approved, or reach other plugins.
